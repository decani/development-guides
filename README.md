# Development Guides

Shared development, deployment and operational documentation used across DKS projects.

This repository contains guides and supporting templates for processes that are useful to more than one application. Application-specific documentation should remain with the application itself.

### Deployment

- [Updating a Deployed JVM Web Application](deployment/webapp-update/webapp-update.md)

## Principles

- Document processes that have actually been used.
- Prefer practical run books over theoretical documentation.
- Keep application-specific configuration in the application repository.
- Store reusable example scripts and configuration alongside the guide that describes them.
- Use obvious `<PLACEHOLDER>` values in templates that must be customised before use.
